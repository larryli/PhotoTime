# PhotoTime - 需求规格说明

## 项目概述

数字照片时间戳管理工具，用于批量处理照片文件的修改时间和 EXIF 时间信息。

---

## 主菜单

### 文件菜单 (&File)

#### 打开文件夹 (&Open folder)

| 项目 | 说明 |
|------|------|
| 功能 | 选择并打开包含照片的文件夹 |
| 快捷键 | 无 |
| 工具栏 | 第一个按钮 |
| 状态逻辑 | 始终可用 |

**详细要求：**
- 弹出标准文件夹选择对话框
- 递归扫描文件夹中的所有照片文件
- 支持 JPEG 格式（.jpg, .jpeg）
- 扫描过程中显示进度：`正在文件夹中查找照片，已找到 %d 张...`
- 扫描完成后显示总数：`共 %d 张照片`
- 支持从资源管理器拖放文件夹到程序窗口

**注意事项：**
- 扫描过程中界面锁定，防止重复操作
- 大量照片时使用虚拟列表提高性能
- 记住上次打开的文件夹路径

#### 重新载入 (&Reload)

| 项目 | 说明 |
|------|------|
| 功能 | 重新扫描当前文件夹，更新照片列表 |
| 快捷键 | 无 |
| 工具栏 | 第二个按钮 |
| 状态逻辑 | 打开文件夹后可用，否则禁用 |

**详细要求：**
- 重新扫描当前打开的文件夹
- 更新照片的文件修改时间和 EXIF 时间信息
- 保留现有的列表排序状态
- 显示进度：`正在重新载入照片，共 %d 张，已重新载入 %d 张...`

**注意事项：**
- 重新载入过程中界面锁定
- 新增的照片添加到列表末尾
- 已删除的照片从列表中移除

#### 导出数据 (&Export)

| 项目 | 说明 |
|------|------|
| 功能 | 将照片列表导出为文件 |
| 子菜单 | TSV 文件、HTML 文件 |
| 状态逻辑 | 打开文件夹后可用，否则禁用 |

##### TSV 文件（Excel）

| 项目 | 说明 |
|------|------|
| 功能 | 导出为制表符分隔的文本文件 |
| 文件类型 | `*.tsv` |
| 默认扩展名 | `.tsv` |

**详细要求：**
- 弹出标准文件保存对话框
- 覆盖已有文件时弹出确认提示
- 导出所有列数据：文件名、子目录、大小、修改时间、Exif时间、文件名时间
- 使用 UTF-8 编码保存
- 显示进度：`正在导出数据...`

##### HTML 文件

| 项目 | 说明 |
|------|------|
| 功能 | 导出为 HTML 表格文件 |
| 文件类型 | `*.html; *.htm` |
| 默认扩展名 | `.html` |

**详细要求：**
- 弹出标准文件保存对话框
- 覆盖已有文件时弹出确认提示
- 生成包含表格的 HTML 文件
- 表格包含所有列数据
- 使用 UTF-8 编码保存
- 显示进度：`正在导出数据...`

#### 自动处理 (&Autoprocess)

| 项目 | 说明 |
|------|------|
| 功能 | 自动同步照片的时间信息 |
| 快捷键 | 无 |
| 工具栏 | 第三个按钮（带下拉箭头） |
| 状态逻辑 | 打开文件夹后可用，否则禁用 |

**详细要求：**
- 处理所有照片的时间信息
- 当 EXIF 时间与文件修改时间不一致时，更新文件修改时间
- 当 EXIF 时间不存在时，使用文件名时间设置 EXIF 和文件修改时间
- 显示进度：`正在自动处理照片，共 %d 张，已处理 %d 张...`

**注意事项：**
- 处理过程中界面锁定
- 修改文件时间需要写入权限
- EXIF 写入可能失败（文件只读或损坏）

|------|------|

## 照片时间处理

### 时间信息来源

| 来源 | 说明 |
|------|------|
| 文件修改时间 | 文件系统的最后修改时间 |
| EXIF 时间 | 照片元数据中的拍摄时间 |
| 文件名时间 | 从文件名解析的时间 |

### 自动处理逻辑

#### 全部处理 (AUTOPROC_ALL)

```
对于每张照片：
  1. 读取文件修改时间
  2. 读取 EXIF 时间
  3. 从文件名解析时间
  4. 如果 EXIF 时间存在：
     - 如果 EXIF 时间与文件修改时间不一致：
       → 更新文件修改时间为 EXIF 时间
  5. 如果 EXIF 时间不存在：
     - 如果文件名时间存在：
       → 设置 EXIF 时间为文件名时间
       → 更新文件修改时间为文件名时间
```

#### 仅文件修改时间 (AUTOPROC_FILE)

```
对于每张照片：
  1. 读取文件修改时间
  2. 读取 EXIF 时间
  3. 如果 EXIF 时间存在：
     - 如果 EXIF 时间与文件修改时间不一致：
       → 更新文件修改时间为 EXIF 时间
```

#### 仅 EXIF 时间 (AUTOPROC_EXIF)

```
对于每张照片：
  1. 读取 EXIF 时间
  2. 从文件名解析时间
  3. 如果 EXIF 时间不存在：
     - 如果文件名时间存在：
       → 设置 EXIF 时间为文件名时间
```

### 支持的文件名格式

| 格式 | 示例 | 说明 |
|------|------|------|
| 标准格式 | `20060102150405.jpg` | 年月日时分秒 |
| 带序号 | `20060102150405.1.jpg` | 带毫秒或序号 |
| 分隔符格式 | `2006-01-02 15.04.05.jpg` | 使用分隔符 |
| 分隔符带序号 | `2006-01-02 15.04.05-1.jpg` | 分隔符带序号 |
| IMG 前缀 | `IMG_20060102_150405.jpg` | 相机默认格式 |
| IMG 带后缀 | `IMG_20060102_150405_HDR.jpg` | 带后缀的相机格式 |
| 微信格式 | `microMsg.1136185445000.jpg` | 微信拍照格式 |
| 微信导出格式 | `mmexport1136185445000.jpg` | 微信导出格式 |
| 微信相机格式 | `wx_camera_1136185445000.jpg` | 微信相机格式 |

### 注意事项

- 修改文件时间需要写入权限
- EXIF 写入可能失败（文件只读或损坏）
- 处理过程中显示进度
- 处理完成后更新列表显示
