# PhotoTime - 待办改进项

## 中优先级 - 照片过滤功能

### 按条件过滤图片

**问题描述：**

当前程序处理所有照片，无法根据特定条件筛选。

**实现方案：**

添加过滤功能，支持按以下条件过滤：
- 时间范围（开始时间 - 结束时间）
- 文件名模式（关键词匹配）
- 时间状态（已同步/未同步）

**实现内容：**
- main.c: 添加过滤对话框
- photo.c: 实现过滤逻辑
- listview.c: 支持过滤后的列表显示

## 远期规划 - 高级功能

### 照片重命名

**功能描述：**

根据时间信息批量重命名照片文件。

**命名格式：**
- `YYYYMMDD_HHMMSS.jpg`
- `YYYY-MM-DD HH.MM.SQ.jpg`
- 自定义格式

### 照片整理

**功能描述：**

按时间自动整理照片到子目录。

**目录结构：**
- `YYYY/MM/DD/`
- `YYYY-MM/`
- 自定义结构

### EXIF 编辑

**功能描述：**

编辑照片的 EXIF 信息。

**可编辑字段：**
- 拍摄时间
- 相机型号
- GPS 信息
- 其他元数据
